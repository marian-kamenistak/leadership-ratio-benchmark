# Leadership Ratio Benchmark

Is your engineering org top-heavy? Compare your manager-to-senior-IC split against a real peer baseline from 3,100+ engineering leaders across Central Europe.

From the [Engineering Leaders Community](https://www.engineeringleaders.io/).

## Use it live

No install — connect the MCP server:

```
claude mcp add -t http elc-toolkit https://www.engineeringleaders.io/mcp
```

Or open the tool in a browser: [The ELC Toolkit](https://www.engineeringleaders.io/engineering-leaders-survival-kit/?ref=skill).

## As a Claude skill

Drop `SKILL.md` into your skills directory, or install with:

```
npx skills add marian-kamenistak/leadership-ratio-benchmark
```
